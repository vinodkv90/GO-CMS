# Go CMS Documentation Audit

Generated by inspecting the actual Go CMS repository (`go.mod`, `cmd/*`, `internal/*`, `pkg/plugin-sdk/*`, `plugins/*`, `themes/default/*`, `admin/package.json`, `scripts/*`, `deployments/*`, `Makefile`, `Dockerfile`, `docker-compose.yml`, and existing `docs/*`).

> Purpose: Establish a single source of truth so all public documentation accurately distinguishes **Implemented**, **Partial / Experimental**, and **Planned / Not Implemented** behavior without inventing commands, endpoints, config keys, or integrations.

## 1. Repository & Version Snapshot

- **Go Module**: `github.com/go-cms/cms` (`go 1.26.10` in `go.mod`)
- **Platform Runtime Version**: `CMSVersion = "1.0.0"` (`internal/api/handlers.go`)
- **Admin Dashboard SPA**: React 19 + TypeScript + Vite 8 + Tailwind CSS v4 (`admin/`, mounted at `/admin/`)
- **Primary Modes**:
  1. **Headless CMS**: REST JSON APIs under `/api/v1/*`, JWT + Opaque API/Transfer Tokens (`cms_pat_`, `cms_adm_`, `cms_trn_`), RBAC, webhooks, OpenAPI/Swagger UI.
  2. **Templated CMS**: Native Go `html/template` renderer (`internal/templates/renderer.go`), theme manager (`themes/`), safe `FuncMap`, XML `/sitemap.xml`, RSS 2.0 `/rss.xml` & `/feed.xml`, draft preview (`?preview=true`).

## 2. Verified Features vs Partial vs Planned / Not Implemented

### Verified Implemented Features
- **Core Server & Observability** (`cmd/server`, `internal/api/server.go`): Chi HTTP router, `RequestID`, `TrustedRealIP`, structured `slog`, panic recovery, security headers (CORS, HSTS in production, CSP), global + auth rate limiting, CSRF double-submit protection (`cms_csrf` / `X-CSRF-Token`), `/healthz`, `/readyz`, `/info`, Prometheus `/metrics`, `/docs` Swagger UI, `/api/v1/openapi.yaml`.
- **PostgreSQL & MySQL Persistence** (`internal/database/postgres`, `mysql`, `migrations`): Full SQL repositories across auth, content, media, settings, email templates, users-permissions, webhooks, localization, audit logs, and plugins state; versioned migrations tracked in `cms_schema_migrations` (`202611080001`, `202611080002`, `202611090001`, `202611120001`).
- **Authentication, Security & RBAC** (`internal/auth`): Argon2id password hashing, HS256 JWT (`issuer: go-cms`, `audience: [go-cms-api]`) + HttpOnly cookie (`cms_token`), Personal/Admin/Transfer tokens (`cms_pat_`, `cms_adm_`, `cms_trn_`, SHA-256 hashed), Admin invitations (`cms_inv_`), TOTP MFA + recovery codes, account lockout/unlock, password policy & expiry reset, admin IP CIDR allowlists, RBAC wildcard matching.
- **Users & Permissions + SSO** (`internal/usersperm`): Isolated end-user app authentication (`/api/v1/app-auth/*`, `go-cms-app-users` JWT audience), app roles, OAuth2 / OIDC discovery and SSO login (`/api/v1/auth/sso/*`, `/api/v1/admin/users-permissions/*`).
- **Content Engine & Content-Type Builder** (`internal/content`, `internal/fields`): `collection`, `single`, and `component` kinds; **22 built-in field types**; component nesting up to `MaxComponentDepth = 8` with cycle detection; separate `draft_data` / `published_data`; optimistic concurrency (`expected_draft_version`); immutable `content_versions` history and restore; soft delete + `?hard=true`; secret hashing & `Private` / `ReadRoles` response redaction; content lifecycle event hooks (`Before/After` Create/Update/Delete/Publish/Unpublish).
- **Templated CMS Engine** (`internal/templates`, `internal/themes`): Native `html/template` with `themes/<slug>/theme.json` (`engine: "go-html-template"`), base layout inheritance (`templates/layouts/base.html`), automatic partial loading (`templates/partials/*.html`), pages (`home.html`, `archive.html`, `article.html`), traversal-guarded theme static asset serving (`/themes/{theme}/assets/*`), `SafeFuncMap` with `bluemonday.UGCPolicy()` sanitization, `/sitemap.xml`, `/rss.xml`, `/feed.xml`, permission-checked draft preview (`?preview=true`).
- **Media Library & Storage Providers** (`internal/media`, `internal/storage`): Folders (`tree`, nested folders, move, contents), asset upload/replace/move/delete, image metadata & responsive variants (`small` 250px, `medium` 500px, `large` 1000px), HMAC-SHA256 signed URLs (`URLSigner`), HLS `.zip` package streaming on filesystem/S3-style backends, hot-swappable `SwappableProvider` across **Local Filesystem** (`local`), **Amazon S3** (`s3`), **MinIO / S3-Compatible** (`minio`), and **Cloudinary** (`cloudinary`, with signed delivery & on-the-fly transforms).
- **Settings, Email, Webhooks, Audit & Caching** (`internal/settings`, `internal/email`, `internal/webhooks`, `internal/audit`, `internal/cache`): Live DB-persisted settings with AES-256-GCM encrypted secrets; SMTP outbound email & editable templates with preview; HMAC-signed outgoing webhooks (9 events + delivery logs); audit logging & CSV export; in-memory & Redis (`go-redis/v9`) cache with tag invalidation.
- **Plugin System (Go Native)** (`pkg/plugin-sdk`, `internal/plugins`): In-process Go `Plugin` interface (`Manifest`, `Init`, `Start`, `Stop`) + `Host` bridge (Logger, `SubscribeEvent`, `RegisterFieldType`, `MountRoute` under `/api/v1/plugins/ext/*`, `GetSetting`, `SetSetting`, `RecordAuditLog`), built-in `audit-log` and `seo-analyzer` plugins, persistent enable/disable/settings state in `cms_plugins_state`.

### Partially Implemented / Bounded Features
- **MongoDB Driver** (`internal/database/mongodb`, `migrations`): Factory connection and the 4 schema/index migrations exist, **but no service packages implement MongoDB repositories** (all core services type-assert `interfaces.SQLDatabase`). Do not present MongoDB as feature-complete at runtime.
- **Content Querying** (`internal/content/handler.go`, `sql_repository.go`): Supports `limit`, `offset`, `sort` (`created_at`, `updated_at`, `slug`, `status` only), `order` (`asc`|`desc`), `search`, `status` (when preview-authorized), `preview=true`, and `hard=true`. Arbitrary `filters[...]`, custom JSON field sorting, `populate=...` query expansion, and `?locale=` filtering on `/content/{uid}` are **not** implemented.
- **Localization** (`internal/localization`): Locale management CRUD (`/api/v1/locales/*`) and RTL/fallback helpers exist, but `/content/{uid}` REST endpoints and template routes do not yet filter by `?locale=`.
- **Full-Text Search** (`internal/search`): TF-IDF inverted index (`GET /api/v1/search`) runs in memory and syncs via publish/delete hooks; not backed by PostgreSQL `tsvector` or external Elasticsearch/Meilisearch.
- **Background Jobs & Multi-Tenancy** (`internal/jobs`, `internal/tenancy`): Both queues/tenant registries are **in-memory** (`X-Tenant-ID` / `?tenant=` / host header resolves tenant context and binds media signed URLs, without row-level SQL isolation across content/media tables).
- **`docs/openapi.yaml`**: Covers 27 paths / 36 operations (`openapi: 3.0.3`), but lags recent backend work (documents `PATCH` instead of `PUT` on `/content/{uid}/{id}`, omits `settings`, `webhooks`, `usersperm`, `mfa`, `tokens`, `themes`, `versions`, and lists 18 instead of 22 field types).

### Unavailable / Planned Features (Do NOT Claim as Working)
- **GraphQL API**: No GraphQL package, schema, or route exists anywhere in Go source code.
- **Google Cloud Storage (`gcs`) & Azure Blob Storage (`azure`)**: Explicitly flagged `Implemented: false` in `SupportedStorageProviders()` and rejected at validation/build time.
- **WebAssembly / External RPC Plugin Isolation**: `docs/PLUGIN-SDK.md` describes Wasm (`wazero`) / RPC sandboxing conceptually, but `go.mod` and `internal/plugins` implement **native Go in-process plugins** (`Plugin` / `Host` SDK) only.
- **Standalone Developer CLI (`cmd/cms` / `gocms create`)**: Does not exist; Go CMS ships three Go CLI binaries (`cms-server`, `cms-migrate`, `cms-rotate-admin`).
- **`/robots.txt` Route**: Not mounted by the HTTP router or template renderer.

## 3. Actual CLI Binaries, Flags & Build Targets

| Binary / Command | Source | Flags / Arguments | Verified Purpose |
|---|---|---|---|
| `cms-server` (`go run ./cmd/server`) | `cmd/server/main.go` | `-config <path>` (default auto-detects `config.yaml`), `-auto-migrate` (bool, default `true`) | Starts HTTP API, Admin SPA (`/admin/`), and Templated Web frontend (`/`). |
| `cms-migrate` (`go run ./cmd/migrate`) | `cmd/migrate/main.go` | `-config <path>`, `<command>`: `up` or `status` | Applies pending DB migrations or inspects applied versions. |
| `cms-rotate-admin` (`go run ./cmd/rotate-admin`) | `cmd/rotate-admin/main.go` | `-config <path>` (default `"config.yaml"`), `-password <pwd>` | Rotates Argon2id password hash for seeded `admin` user in `cms_users`. |
| `make` | `Makefile` | `build`, `build-admin`, `test`, `test-coverage`, `lint`, `run`, `migrate-up`, `migrate-status`, `docker-up`, `docker-down`, `backup`, `restore`, `clean` | Local build, test, Admin SPA build, Docker, and backup workflows. |
